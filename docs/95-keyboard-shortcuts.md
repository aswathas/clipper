# Keyboard shortcuts

**Global**
- `Ctrl+Shift+C` — capture URL
- `Ctrl+Shift+X` — capture image
- `Ctrl+Shift+M` — Muse pause/resume

**Dashboard**
- `/` — search
- `>` — actions
- `j` / `k` — next / prev
- `space` — toggle select
- `a` — archive
- `l` — promote to library
- `t` — tag
- `e` — edit
- `?` — show shortcuts
